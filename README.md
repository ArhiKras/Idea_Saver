# 🤖 Telegram-бот для командной работы с задачами

Простой Telegram-бот для совместного управления задачами. Бот позволяет добавлять задачи в общий список, просматривать их и экспортировать в CSV формат.

## 📋 Возможности

- ➕ **Добавление задач** - сохранение задач с указанием автора и времени
- 📋 **Просмотр списка** - вывод всех задач с деталями
- 📄 **Экспорт в CSV** - скачивание всех задач в удобном табличном формате
- 💾 **База данных SQLite** - надежное хранение данных

## 🛠️ Технологии

- Python 3.7+
- aiogram 3.x - современная библиотека для создания Telegram-ботов
- aiosqlite - асинхронная работа с SQLite
- python-dotenv - загрузка переменных окружения из .env
- SQLite3 - легкая встроенная база данных

## 🚀 Установка и запуск

### 1. Создайте виртуальное окружение

```bash
python -m venv venv
```

### 2. Активируйте виртуальное окружение

**Windows:**
```bash
venv\Scripts\activate
```

**Linux/macOS:**
```bash
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Получите токен бота

1. Найдите бота [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен

### 5. Настройте конфигурацию

Создайте файл `.env` в корне проекта и добавьте в него ваш токен бота:

```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

Замените `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz` на токен, полученный от @BotFather.

### 6. Запустите бота

```bash
python main.py
```

После запуска вы увидите сообщение: "🤖 Бот запущен и готов к работе!"

## 📱 Как использовать

### Команды бота:

- `/start` - Приветствие и список команд
- `/add <текст>` - Добавить новую задачу
- `/list` - Показать все задачи
- `/list_csv` - Скачать задачи в CSV формате

### Примеры:

```
/add Подготовить презентацию к совещанию
/add Обновить документацию проекта
/list
/list_csv
```

Также можно использовать кнопки для удобства:
- ➕ Добавить задачу
- 📋 Список задач
- 📄 Скачать CSV

## 💾 База данных

Бот использует SQLite базу данных `tasks.db` со следующей структурой:

**Таблица tasks:**
- `id` - Уникальный идентификатор (автоинкремент)
- `text` - Текст задачи
- `user` - Имя пользователя, добавившего задачу
- `created_at` - Дата и время создания

## 🔒 Безопасность

⚠️ **ВАЖНО:** Не храните токен бота в публичных репозиториях!

Для продакшена рекомендуется:
1. Использовать переменные окружения для хранения токена
2. Добавить `.env` файл в `.gitignore`
3. Использовать библиотеку `python-dotenv` для загрузки переменных

## 🤝 Поддержка

Если у вас возникли вопросы или проблемы:

**Ошибка "Токен бота не найден":**
- Убедитесь, что создан файл `.env` в корне проекта
- Проверьте правильность токена в файле `.env`

**Ошибка "Module not found":**
- Убедитесь, что виртуальное окружение активировано
- Переустановите зависимости: `pip install -r requirements.txt`

**Бот не отвечает:**
- Проверьте подключение к интернету
- Убедитесь, что программа запущена и работает
