# 🤖 Telegram-бот для командной работы с задачами (Расширенная версия)

Мощный Telegram-бот для совместного управления задачами в команде. Бот позволяет добавлять задачи с расширенными параметрами, управлять статусами, назначать ответственных и экспортировать данные в CSV.

## ✨ Новые возможности

### 🎯 Расширенное управление задачами:
- **Статусы задач**: новое, в работе, выполнено
- **Категории**: frontend, backend, database
- **Дедлайны**: с проверкой просроченных задач
- **Ответственные**: назначение исполнителей из команды
- **Авторизация**: автоматическая регистрация пользователей

### 🎨 Современный интерфейс:
- Inline-кнопки для быстрого управления задачами
- Фильтрация задач по категориям
- Визуальные индикаторы статусов и дедлайнов
- Интерактивные меню для изменения параметров

## 📋 Основные возможности

- ➕ **Добавление задач** с категориями, дедлайнами и ответственными
- 📊 **Управление статусами** через удобные inline-кнопки
- 📁 **Фильтрация по категориям** для быстрого поиска
- 👤 **Персональные задачи** - просмотр своих назначений
- 📄 **Экспорт в CSV** со всеми параметрами
- 💾 **База данных SQLite** с таблицами пользователей и задач
- 🔒 **Авторизация** по Telegram ID

## 🛠️ Технологии

- Python 3.7+
- aiogram 3.x - современная библиотека для создания Telegram-ботов
- aiosqlite - асинхронная работа с SQLite
- python-dotenv - загрузка переменных окружения
- SQLite3 - легкая встроенная база данных

## 🚀 Установка и запуск

### 1. Создайте виртуальное окружение

```bash
python -m venv venv
```

### 2. Активируйте виртуальное окружение

**Windows:**
```bash
venv\Scripts\activate
```

**Linux/macOS:**
```bash
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Получите токен бота

1. Найдите бота [@BotFather](https://t.me/BotFather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Скопируйте полученный токен

### 5. Настройте конфигурацию

Создайте файл `.env` в корне проекта и добавьте в него ваш токен бота:

```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

Замените `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz` на токен, полученный от @BotFather.

### 6. Запустите бота

```bash
python main.py
```

После запуска вы увидите:
```
🤖 Бот запущен и готов к работе!
```

## 📱 Как использовать

### Команды бота:

- `/start` - Начало работы и регистрация
- `/add` - Добавить новую задачу (с выбором категории, дедлайна, ответственного)
- `/list` - Показать все задачи с фильтрацией по категориям
- `/my_tasks` - Показать только мои задачи (где я ответственный)
- `/list_csv` - Скачать все задачи в CSV формате

### Кнопки меню:

- ➕ **Добавить задачу** - создание новой задачи
- 📋 **Список задач** - просмотр всех задач
- 👤 **Мои задачи** - задачи где вы ответственный
- 📄 **Скачать CSV** - экспорт данных

### 🎯 Процесс добавления задачи:

1. Нажмите `/add` или кнопку "Добавить задачу"
2. Введите текст задачи
3. Выберите категорию (Frontend/Backend/Database)
4. Укажите дедлайн (ДД.ММ.ГГГГ) или пропустите (-)
5. Выберите ответственного из списка пользователей

### 📊 Управление задачами:

При просмотре списка задач каждая задача имеет кнопки:
- **📊 Изменить статус** - новое → в работе → выполнено
- **📁 Изменить категорию** - frontend/backend/database
- **🗑 Удалить задачу** - удаление задачи

### 📋 Фильтрация:

При вызове `/list` доступны кнопки фильтрации:
- 🎨 Frontend
- ⚙️ Backend
- 💾 Database
- 🔄 Все

## 💾 База данных

Бот использует SQLite базу данных `tasks.db` с двумя таблицами:

### Таблица `users`:
- `id` - Уникальный идентификатор (автоинкремент)
- `telegram_id` - Telegram ID пользователя
- `username` - Username в Telegram
- `full_name` - Полное имя пользователя
- `created_at` - Дата регистрации

### Таблица `tasks`:
- `id` - Уникальный идентификатор (автоинкремент)
- `text` - Текст задачи
- `user_id` - ID создателя задачи (ссылка на users)
- `status` - Статус (новое/в работе/выполнено)
- `category` - Категория (frontend/backend/database)
- `deadline` - Дедлайн в формате ДД.ММ.ГГГГ
- `assignee_id` - ID ответственного (ссылка на users)
- `created_at` - Дата и время создания

## 📊 Формат CSV экспорта

## 🤝 Поддержка

Если у вас возникли вопросы или проблемы:

**Ошибка "Токен бота не найден":**
- Убедитесь, что создан файл `.env` в корне проекта
- Проверьте правильность токена в файле `.env`

**Ошибка "Module not found":**
- Убедитесь, что виртуальное окружение активировано
- Переустановите зависимости: `pip install -r requirements.txt`

**Бот не отвечает:**
- Проверьте подключение к интернету
- Убедитесь, что программа запущена и работает
- Проверьте логи на наличие ошибок

**База данных не создается:**
- Проверьте права на запись в директорию проекта
- Убедитесь, что SQLite установлен (входит в стандартную поставку Python)
