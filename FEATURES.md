# ✨ Возможности расширенного бота

## 🎯 Краткий обзор

Этот Telegram-бот предоставляет полноценную систему управления задачами для команды с возможностью назначения ответственных, установки дедлайнов, отслеживания статусов и организации по категориям.

---

## 📋 Основные функции

### 1. 👥 Авторизация пользователей

**Автоматическая регистрация при первом запуске**

- При команде `/start` бот автоматически регистрирует пользователя
- Сохраняется: Telegram ID, username, полное имя
- Все зарегистрированные пользователи доступны для назначения ответственными

**Безопасность:**
- Проверка Telegram ID перед каждой операцией
- Автоматическая регистрация новых пользователей

---

### 2. ➕ Добавление задач

**Многоэтапный процесс создания задачи:**

1. **Текст задачи** - описание того, что нужно сделать
2. **Категория** - выбор из: Frontend, Backend, Database
3. **Дедлайн** - формат ДД.ММ.ГГГГ (или пропустить)
4. **Ответственный** - выбор из списка зарегистрированных пользователей

**Пример использования:**
```
/add
→ "Разработать API для авторизации"
→ Backend
→ 31.12.2024
→ Иван Иванов
✅ Задача #5 создана!
```

**Особенности:**
- FSM (конечный автомат) для пошагового ввода
- Валидация формата дедлайна
- Возможность пропустить необязательные поля
- Inline-кнопки для выбора категории и ответственного

---

### 3. 📊 Управление статусами

**Три статуса задачи:**
- 🆕 **Новое** - задача только создана
- ⚙️ **В работе** - задача в процессе выполнения
- ✅ **Выполнено** - задача завершена

**Как изменить статус:**
1. Открыть задачу из списка
2. Нажать "📊 Изменить статус"
3. Выбрать новый статус из меню
4. Получить подтверждение

**Автоматика:**
- Новые задачи автоматически получают статус "новое"
- Статус отображается везде: в списке, в деталях, в CSV

---

### 4. 📁 Категории задач

**Три категории:**
- 🎨 **Frontend** - задачи по пользовательскому интерфейсу
- ⚙️ **Backend** - серверная логика, API
- 💾 **Database** - работа с базами данных

**Функции:**
- Выбор категории при создании задачи
- Изменение категории у существующей задачи
- Фильтрация списка задач по категориям
- Визуальные индикаторы (эмодзи)

---

### 5. 📅 Дедлайны

**Формат:** ДД.ММ.ГГГГ (например: 31.12.2024)

**Возможности:**
- Установка дедлайна при создании задачи
- Опциональное поле (можно пропустить)
- Автоматическая проверка просрочки
- Визуальное предупреждение (⚠️) для просроченных задач

**Пример:**
```
📅 Дедлайн: 15.11.2024         ✅ В срок
📅 Дедлайн: ⚠️ 01.11.2024     ❌ Просрочено!
📅 Дедлайн: Не указан           ℹ️ Без срока
```

---

### 6. 👤 Назначение ответственных

**Функции:**
- Выбор ответственного из списка зарегистрированных пользователей
- Возможность создать задачу без ответственного
- Команда `/my_tasks` для просмотра своих назначений

**Процесс:**
1. При создании задачи бот показывает список пользователей
2. Выбираете ответственного или "Без ответственного"
3. Ответственный указывается в деталях задачи

**Команда /my_tasks:**
- Показывает только задачи, где вы ответственный
- Удобно для контроля личной загрузки
- Фильтрует по вашему user_id

---

### 7. 📋 Просмотр списка задач

**Команда /list:**

**Фильтрация:**
- Кнопки для быстрой фильтрации по категориям
- Frontend / Backend / Database / Все

**Что отображается:**
- Номер задачи (#ID)
- Текст задачи
- Статус с эмодзи
- Категория с эмодзи
- Дедлайн (с предупреждением если просрочен)
- Создатель задачи
- Ответственный
- Дата создания

**Интерактивность:**
- Каждая задача кликабельна (в будущих версиях)
- Длинные списки автоматически разбиваются на части

---

### 8. 🎛️ Управление задачами (Inline-кнопки)

**Для каждой задачи доступны действия:**

1. **📊 Изменить статус**
   - Открывает меню выбора статуса
   - Новое / В работе / Выполнено
   - Мгновенное обновление

2. **📁 Изменить категорию**
   - Открывает меню выбора категории
   - Frontend / Backend / Database
   - Сохраняет изменения в БД

3. **🗑 Удалить задачу**
   - Полное удаление задачи из системы
   - Без подтверждения (будьте осторожны!)

4. **◀️ К списку / Назад**
   - Навигация по меню
   - Возврат к предыдущему экрану

---

### 9. 📄 Экспорт в CSV

**Команда /list_csv:**

**Что экспортируется:**
- ID задачи
- Текст задачи
- Статус
- Категория
- Дедлайн
- Создатель
- Ответственный
- Дата создания

**Формат:**
- UTF-8 с BOM (правильно открывается в Excel)
- Разделитель: запятая
- Кодировка: utf-8-sig

**Использование:**
- Откройте в Excel или Google Sheets
- Создайте отчеты и графики
- Фильтруйте и сортируйте данные
- Поделитесь с командой

## 🔐 Безопасность

### Авторизация:
- Каждый пользователь регистрируется по Telegram ID
- ID не может быть подделан
- Автоматическая проверка перед операциями

### Токен бота:
- Хранится в .env файле (не в коде!)
- .env добавлен в .gitignore
- Не попадает в репозиторий

### База данных:
- Локальное хранение (tasks.db)
- SQLite - проверенное решение
- Автоматические backup'ы (рекомендуется настроить)

## 🚀 Производительность
